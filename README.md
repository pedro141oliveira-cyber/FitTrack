# FitTrack 🏋️

### Aplicativo de Gerenciamento de Exercícios Físicos

O **FitTrack** é um aplicativo mobile desenvolvido com React Native e Expo, com o objetivo de auxiliar os usuários na organização e no acompanhamento de suas atividades físicas.

O projeto oferece uma interface simples, intuitiva e moderna, permitindo visualizar exercícios, acompanhar o progresso dos treinos e consultar informações específicas de cada atividade.

## 🎯 Objetivo do Projeto

Desenvolver uma aplicação mobile que facilite o gerenciamento de exercícios físicos, proporcionando uma experiência prática de acompanhamento das atividades e evolução dos treinos.

## 🚀 Funcionalidades

- **Tela inicial:** apresentação do aplicativo e acesso às funcionalidades.
- **Lista de exercícios:** visualização dos exercícios disponíveis.
- **Detalhes dos exercícios:** consulta das informações de cada atividade.
- **Séries e repetições:** acompanhamento das metas de cada exercício.
- **Barra de progresso:** visualização dos exercícios concluídos.
- **Conclusão de exercícios:** possibilidade de marcar atividades como realizadas.
- **Cronômetro:** recurso de controle de tempo durante os exercícios.

## ⚙️ Como Executar o Projeto

### 1. Pré-requisitos

- Node.js instalado.
- npm instalado.
- Expo Go instalado no celular.

### 2. Clonar o repositório

```bash
git clone https://github.com/pedro141oliveira-cyber/FitTrack.git
```

### 3. Entrar na pasta

```bash
cd FitTrack
```

### 4. Instalar as dependências

```bash
npm install
```

### 5. Iniciar o aplicativo

```bash
npx expo start
```

Após iniciar, escaneie o QR Code com o aplicativo Expo Go para visualizar o FitTrack no celular.
